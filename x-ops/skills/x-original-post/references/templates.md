# Post templates (English). Free tier: trim to ≤280 chars, overflow → self-reply.

**T1 News (screenshot/video)**
```
BREAKING: {Company} just {launched/rolled out} {Product}.
- {Key spec / number}
- {Pricing / availability}
- {What's different vs {competitor}}
Why it matters: {one-line take}.
```
Self-reply: `Source: {link}`

**T2 First-person test**
```
I tested {Product} for {time/task} so you don't have to.
What worked: - {…}
What broke: - {…}
Verdict: {use it for X, skip it for Y}.
```
Media: before/after screenshots or screen recording.

**T3 Comparison card**
```
{Model A} vs {Model B}, the numbers that matter:
→ Price: {a} vs {b}
→ Context: {a} vs {b}
→ {Benchmark}: {a} vs {b}
My pick for builders: {…}
```

**T4 One-liner + video** — `{Surprising one-liner about what the AI did}. {Short reaction}` + 15–40s clip (AiBreakfast/minchoi style).

**T5 Trend take** — `Clear AI trend I'm seeing:\n\n{obs 1}\n{obs 2}\n\n{punchline}.` Can be text-only (mattshumer_ 560K).

**T6 Weekly recap (pin)** — `This week in AI, the 7 things that actually matter 🧵 1…7. Bookmark this. Follow @Gotwei for one of these every week.`

**T7 Rumor/preview** — `{Company} appears to be preparing {feature} (unconfirmed).\nSpotted: {code strings / changelog / leak}.\nIf true: {implication}.\nWill update when it's official.` (testingcatalog, btibor91)

**T8 Pricing/policy change** — `{Company} quietly changed {pricing/limits}:\nBefore: {…}\nNow: {…}\nWho this hurts: {…}\nWho this helps: {…}`

**T9 Scoop one-liner (btibor91)** — `{Company} is preparing {specific thing} 👀` + code/UI/changelog screenshot with red box. Self-reply: `Spotted in: {where}. Not official yet.`

**T10 Expert quote (haider1, Hesamation)** — `{Expert, title}:\n\n"{1–2 sentence quote}"\n\n{why this matters for AI builders}` + ≤60s clip or sourced screenshot.

**T11 Infographic/map (AndrewYNg)** — `New: {a map/cheatsheet} of {topic}.\n\n{1 line on how to use it}` + own infographic. Highest bookmark rate; good pin.

(Reply template T12 lives in x-reply.)

## v2.4 templates (2026-10-17, from creator deep sample — links/metrics in evidence.md)

**T13 Availability line** — `{Product/model} is now {free / in beta / open-weight} in {platform}.` Optional 1–3 bullets. Works when the fact itself is big (opencode 43 chars, 3.5M; OpenAIDevs "Now in beta: …" + video 1.8M).

**T14 Launch + spec bullets + clip** (krea_ai 452K, 21×)
```
{Company} just opened {product} — {one-line what it does}.
- {spec with number}
- {spec with number}
- {availability / price}
{one-line take}
```
Media: official demo clip (video > image this run). Self-reply: source + extra detail.

**T15 Clear opinion** (Sentdex 102K, 15×) — `In my opinion, the best {category} right now is {X}.

{reason with a number}. {reason}.

{caveat / who should skip it}.`

**T16 Scoop alert** (SemiAnalysis_ 927K, 23×) — `ALERT 🚨: {specific, checkable claim}.
{evidence: who/what/where}.
{implication}.` Only with a real source; else "Reportedly…".

**T17 Discovery list** (mdancho84 40K, 12×, 1,067 bookmarks) — `Someone built {a free X} on GitHub.

Not {a}.
Not {b}.
{what it actually is}.

- {item}
- {item}
- {item}` + screenshot. High bookmark format.

**T18 Reaction with a number** (yoavgo 129K, 14×) — `wait what?? {surprising number/comparison}.` Use as a quote only on a big post (quotes lose in 66% of accounts overall).

Length: aim 120–280 chars; always add a self-reply with source + one extra detail (originals with a self-reply won in 79% of accounts).
