# X visuals

1. Every original carries media (media 66% win, 1.28×; video 1.50×; images 1.15× — v2.2). Priority: official demo clip 15–40s (≤60s for interviews) > official page/changelog/pricing screenshot with red box on the key part > own card.
2. Brand: cream **#F5F1E8** background, dark green **#1F4D3A** accent, ink #1C1C1A, muted #6B6A63, Inter font, footer "Wei AI · @Gotwei". *Supersedes v1 "dark background + wei news logo".*
3. Templates in `/workspace/gotwei/templates`: `news_card.py` (source tag, headline ≤3 lines, ≤3 points) and `data_card.py` (2–4 comparison columns, one highlighted). Size 1600×900 (1080×1350 ok for portrait). Output to `/workspace/gotwei/images/YYYY-MM-DD-HHMM-<slug>.png`.
4. Headline ≤8 words, ≤3 numbers. Image text complements the post body, never repeats it.
5. Crop screenshots to the essential UI. For mega-post replies, an early image/GIF + short caption wins.
6. Infographics/cheatsheets earn the most bookmarks (AndrewYNg map: 52,550 bookmarks) — good pin material.
