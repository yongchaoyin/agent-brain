# Agent Brain

One cloud memory for all your AI agents. Teach one agent once; every MCP-capable agent you sign in to shares the same persona, memories, rules and skills, synced in real time with full version history.

一个给所有 AI agent 共用的云端大脑：在一个 agent 里调教好的东西，换到任何支持 MCP 的 agent，登录后就能直接用，实时同步，并保留完整历史版本。
