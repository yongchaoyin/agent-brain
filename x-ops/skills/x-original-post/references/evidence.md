# Original-post evidence (API study 2026-10-16)

Method: v1 = 51 top AI accounts, 1287 posts (445 originals, 817 replies) + @Gotwei's last 25. v2 = 112 accounts / 3362 posts, **within-account paired comparison** (A vs B relative-impression medians in the same account, ≥3 each, small items ≥2; report % accounts where A wins + median ratio). v2.1 = 178 / 5220. v2.2 = ~774 accounts with posts, 5296 posts (2279 orig, 3017 replies); ~18 short-window accounts re-sampled to ~30 days (AnthropicAI 27.1d, hardmaru 21.5d, swyx 7.5d, bcherny 6.9d). "Relative impressions" = post impressions ÷ account's median original impressions; viral = ≥3×.
